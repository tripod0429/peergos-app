### About

Peergos is a peer-to-peer, end-to-end encrypted global filesystem with fine-grained access control.

The server only ever sees encrypted data, and your identity is not tied to one server: you can log in through any Peergos instance and interact with users on other servers.

### Features

* File storage and sharing, with secret links
* Calendar and address book
* Social feed
* Private websites
* Sandboxed third-party apps
